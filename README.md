# مشروع جارفس - Kotlin / Android

## المميزات المبنية فعليًا بالكود (نسخة محدَّثة)
- محادثة ذكية عبر **Gemini API** (المحرك الأساسي)، مع خادم احتياطي اختياري (`ONLINE_CHAT_ENDPOINT`) يشتغل تلقائيًا لو Gemini غير مفعّل أو فشل الاتصال
- كلمة تفعيل صوتية "جارفس" + استماع خلفي دائم يشتغل حتى لو التطبيق مغلق (`JarvisWakeService`)
- تعديل الصوت: جنس الصوت (رجالي/أنثوي) + 3 أشرطة تحكم حية (العمق، الخشونة، البحة)
- تبديل بين 6 لغات (عربي، فرنسي، إنجليزي، إسباني، روسي، صيني) بالصوت أو بزر مخصص
- وضع ملاحة كامل: موقع حقيقي + ترميز عكسي (حي/بلدية/ولاية) + وجهات سريعة (منزل/عمل/جامعة) + نقاط مخصصة (Waypoints) + ملاحة حقيقية عبر خرائط Google
- حالة شبكة حقيقية (WiFi/بيانات/بلوتوث/IP)
- ماسح نصوص (OCR، إنجليزي/فرنسي فقط) لحفظ ملاحظات قابلة للبحث
- كاتب ملاحظات صوتي فوري بزر واحد (مع تلخيص تلقائي للملاحظات الطويلة عبر Gemini)
- مؤقت بومودورو + تتبع جلسات التركيز اليومية
- جدول جامعي (إضافة محاضرات، عرض جدول اليوم/الأسبوع)
- تذكير سنوي بالمناسبات (أعياد ميلاد، مناسبات) عبر إشعار حقيقي
- ملخص صباحي يومي (طقس حقيقي + أقرب موعد + خبر عاجل)، بصوت أو كإشعار
- تقدير وقت الطريق مع مراعاة الزحمة الحالية (يحتاج مفتاح Google Maps API اختياري)
- لوحة قيادة تنفيذية (أقرب موعد، جلسات تركيز، نسبة إنتاجية)
- "العين التخيلية": تطبيق أسلوب فني على صورة عبر TensorFlow Lite (يحتاج ملفات نموذج يدوية، راجع التعليمات في المحادثة)
- خصائص أمان شخصي: مكالمة وهمية، إرسال موقع SOS، جهة اتصال طوارئ
- تحويل عملات ووحدات (كم/ميل، كيلو/باوند، مئوية/فهرنهايت، دولار/يورو/دينار/ريال)
- ملف شخصي (اسم، إيميل، هاتف، جهة اتصال طوارئ)
- تشغيل/إطفاء الفلاش، حاسبة بسيطة، تشغيل موسيقى، تحويل نص لصوت بالعربي

## خطوات التشغيل
1. حمّل **Android Studio** (مجاني) من الموقع الرسمي على جهاز فيه على الأقل 8 جيجا رام
   - إذا جهازك الحالي ما يكفي، جرب **Gitpod** أو **GitHub Codespaces** (بيئة تطوير أونلاين مجانية بالمتصفح، ما بتحتاج جهاز قوي)
2. افتح المجلد كمشروع Android موجود (Open an existing project)
3. ضيف ملف موسيقى باسم `sample_music.mp3` داخل:
   `app/src/main/res/raw/`
4. اضغط Run لتثبيته على هاتفك (لازم تفعّل وضع المطوّر + USB Debugging على الهاتف)

## لتفعيل خادم محادثة احتياطي (اختياري، غير ضروري إذا Gemini شغّال)
افتح ملف `MainActivity.kt` وعدّل هذا السطر:
```kotlin
private val ONLINE_CHAT_ENDPOINT = ""
```
حطلها رابط أي API ترجع رد نصي (نص خام أو JSON فيه حقل `reply`/`response`/`text`). يشتغل تلقائيًا فقط لو Gemini غير مفعّل (مفتاح فارغ) أو فشل الاتصال به.

## لتفعيل تقدير وقت الطريق مع الزحمة (اختياري)
ضيف مفتاح `GOOGLE_MAPS_API_KEY` في `local.properties` (فيه حصة مجانية شهرية من Google).

## لتفعيل "العين التخيلية" (اختياري)
حمّل 3 ملفات (نموذجين TFLite + صورة أسلوب فني) وحطهم في `app/src/main/assets/` — راجع أسماء الملفات وروابط التحميل في تعليقات `StyleTransferHelper.kt`.

## ملاحظات مهمة
- الصلاحيات (مايك، كاميرا، إشعارات) لازم يوافق عليها المستخدم أول مرة يفتح التطبيق
- على أندرويد 12+ ممكن تحتاج توافق يدوي إضافي على صلاحية "Schedule Exact Alarm" من إعدادات النظام
- على أندرويد عمومًا، لازم توقف "تحسين البطارية" لهذا التطبيق يدويًا باش الاستماع الخلفي يبقى شغّال بثبات
- التعرف على الصوت هون يستخدم خدمة أندرويد المدمجة (تحتاج نت لمعظم الأجهزة)؛ للتعرف الصوتي الأوفلاين بالكامل تحتاج مكتبة إضافية زي Vosk
- ماسح النصوص (OCR) يدعم فقط الحروف اللاتينية حاليًا، وليس العربية
